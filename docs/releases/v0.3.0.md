## 1. Executive Summary

This milestone delivers the comprehensive student-facing academic secretary mobile application for **LAFINA-CAPSTONE**. Migrated from the refined `LAFINA` design system and aligned with the `LAFINA-backend` personal SQLite schema and cloud sync architecture, the app provides a resilient, offline-first personal workspace for university students.

Key milestones delivered in v0.3.0:
- **Student UI/UX Migration:** Complete student UI/UX ported from `LAFINA`, including `SynthSplash`, `AuthBackdrop` + `Grainient` (native OpenGL/SurfaceView implementation), `WelcomeScreen`, `LoginScreen`, `RegisterScreen`, `OnboardingScreen`, `ProfileScreen`, `PreferencesSettingsScreen`, `CustomTabBar`, and `ProductTour`.
- **Backend-Aligned SQLite Schema:** Unified SQLite database (`lafina.db`) matching `LAFINA-backend` personal models across 7 core entities (`profile`, `task`, `event`, `time_block`, `reminder`, `note`, `custom_category`) with transactional `sync_outbox` logging.
- **Offline Guest Mode & Cloud Accounts:** Zero-barrier offline guest mode (`local_guest_user`) with seamless, atomic one-way migration to authenticated student cloud accounts (`student`, `student_pro`, `admin`).
- **Fast Local TTS Engine:** Replaced heavy Kokoro 82M ONNX model binaries with native `react-native-tts`, delivering sub-100ms speech synthesis latency, zero model load lag, and eliminating ~85 MB of binary payload.
- **Academic Calendar & Scheduling:** Week View timeline, 7-day grid Month View, Philippine national holiday banners, timed tasks, campus events, and minute-accurate focus time blocks with collision handling.
- **RFC 5545 Recurrence & iCalendar Interoperability:** Zero-dependency recurrence rule expansion (`DAILY`, `WEEKLY`, `MONTHLY`, `YEARLY`) and full `.ics` import/export support for university timetables.
- **Lecture Notes Workspace:** Markdown and checklist editor (`- [ ]` / `- [x]`) with native formatting toolbar, live preview, pinned notes, category tagging, search, and drag-and-drop reordering.
- **Native Android Exact Alarm Subsystem:** Reliable alarm delivery via `AlarmManager.setExactAndAllowWhileIdle`, persistent `SharedPreferences` registry, and heads-up notifications with full-screen intent over keyguard.
- **Decoupled Alert Acknowledgment:** Answering, dismissing, or snoozing an alert updates reminder status to `acknowledged`, while strictly preserving the underlying task's incomplete status (`isCompleted === false`).
- **Lifecycle & Reboot Recovery:** Reschedules all pending alarms across device reboots (`BOOT_COMPLETED`), timezone adjustments (`TIMEZONE_CHANGED`), and app updates (`MY_PACKAGE_REPLACED`), triggering near-due alerts (<3m) and marking stale alerts (>15m) as `missed`.
- **Strict Scope Boundary Enforcement:** Strictly zero business dashboards, business roles, company chat, Gmail APIs/OAuth, study tools (Pomodoro, Flashcards, Study Notes, Meetings), or Kokoro ONNX model binaries.

## 2. Phase 01 Technical Implementation: Student UI/UX Foundation, Local Storage & Fast TTS

### Design Tokens & Dynamic Theming (`src/ui/theme/`, `ThemeContext.tsx`)
- Centralized semantic design tokens (`Colors`, `Fonts`, `FontSize`, `Spacing`, `Layout`, `Shadows`).
- Dark mode, light mode, and system preference detection via `ThemeContext`.
- Native circular theme reveal animation via `LafinaThemeRevealModule.kt`.
- Reusable styling hooks (`useThemedStyles`, `useTheme`) ensuring consistent layout hierarchy across all screens.

### Visual Shell & Onboarding
- **`SynthSplash.tsx`:** Multi-strand procedural bezier spline splash animation with easing and brand reveal.
- **`AuthBackdrop.tsx` & `LafinaGrainientView.kt`:** Hardware-accelerated native Android SurfaceView utilizing custom OpenGL shaders to render animated grain-gradient backdrops behind authentication screens.
- **Student Authentication & Onboarding Screens:** `WelcomeScreen`, `LoginScreen`, `RegisterScreen`, and `OnboardingScreen` capturing academic degree, year level, target study hours, and wake/sleep schedules.
- **Navigation Shell:** `CustomTabBar` with floating action button (FAB) action triggers and animated tab switches.
- **`ProductTour.tsx`:** Interactive walkthrough modal guiding new students through calendar, notes, AI secretary, and reminder features.

### SQLite Local Data Engine (`src/storage/dbInit.ts`)
- Native SQLite initialization via `@op-engineering/op-sqlite`.
- Personal database schema matching `LAFINA-backend`:
  - `users`: Core profile, role (`student`, `student_pro`, `admin`), time preferences, and UI theme.
  - `user_preferences`: Academic notification lead times, snooze tendencies (`snooze_once`, `snooze_multiple`, `strict_no_snooze`), and calendar layout preferences.
  - `tasks`, `events`, `time_blocks`, `reminders`, `notes`, `custom_categories`: 7 personal entity tables with UTC ISO timestamps, priority, color tagging, and recurrence metadata.
  - `sync_outbox`, `sync_metadata`, `sync_state`, `sync_conflicts`: Cloud sync tracking tables ensuring offline changes are queued with monotonic mutation IDs.

### Fast Local TTS Engine (`src/ai/tts/ttsService.ts`)
- Implemented speech synthesis utilizing `react-native-tts` as the primary offline/local voice engine.
- Replaced the legacy Kokoro 82M ONNX model (`kokoro-v0_19.onnx`, `af_bella.bin`, `cmudict.txt`), reducing APK footprint by ~85 MB and slashing memory usage by >250 MB.
- Cloud TTS fallback hook configured for `LAFINA-backend` Gemini TTS endpoint (`/v1/ai/tts`) with automatic, silent fallback to local `react-native-tts` when offline.

## 3. Phase 02 Technical Implementation: Calendar, Tasks, Time Blocks, Notes & Guest Migration

### Student Calendar Workspace (`src/ui/screens/calendar/`)
- **Interactive View Modes:** Switchable Week View (with continuous timeline strip and hour markers) and 7-day grid Month View.
- **Time Grid Positioning (`timeGridLayout.ts`):** Exact pixel-aligned layout for multi-hour events and overlapping blocks with collision handling.
- **Philippine National Holidays (`philippineHolidays.ts`):** Built-in calendar banner indicating official regular and special non-working holidays.
- **Schedule Modals (`AddTaskEventModal.tsx`, `AddBlockModal.tsx`):** Fast creation and editing of timed tasks, date-only tasks, multi-hour campus lectures, and focus study blocks.

### RFC 5545 Recurrence Engine (`src/storage/rruleHelper.ts`)
- Zero-dependency recurrence rule parser and occurrence generator.
- Supports `DAILY`, `WEEKLY` (with `BYDAY` parsing and interval skipping), `MONTHLY`, and `YEARLY` recurrence.
- Safety bound capped at 1,000 occurrences to guarantee deterministic execution and protect against infinite loops.

### iCalendar (.ics) Interoperability (`src/storage/icsHelper.ts`, `calendarImportPersistence.ts`)
- RFC 5545 generator and parser for academic timetable import and export.
- Supports importing university course timetables directly into local SQLite.
- Layer management (`CalendarLayersModal.tsx`, `calendarVisibilityStore.ts`, `importedBatchesStore.ts`) allowing students to toggle visibility of imported layers or delete imported batches in a single operation.

### Lecture Notes Workspace (`src/ui/screens/notes/`)
- **Note Management:** Grid/list view toggling, pinned notes sorting, category filtering chips, search, and drag-and-drop reordering.
- **Markdown & Checklist Editor (`NoteEditor.tsx`, `NoteBody.tsx`):** Full-screen lecture note editor with live markdown preview, formatting toolbar (`noteEditing.ts`, `noteMarkdown.ts`), and interactive checkboxes (`- [ ]` / `- [x]`) rendered via native view trees.
- **Custom Categories:** Custom academic category management with distinct color chips, synchronized atomically with `sync_outbox`.

### Guest-to-Cloud Migration (`src/storage/guestMigration.ts`)
- Atomic migration utility re-keying all 7 personal entities from `local_guest_user` to the authenticated student cloud account upon registration/login.
- Enqueues atomic outbox mutations to ensure no offline study data is lost during account creation.

## 4. Phase 03 Technical Implementation: Durable Native Android Reminder Alarms & Lifecycle Recovery

### Native Android Alarm Subsystem (`android/app/src/main/java/com/lafina/capstone/`)
- **`LafinaReminderModule.kt`:** Native module registered as `NativeModules.LafinaReminder`.
  - Schedules exact alarms via `AlarmManager.setExactAndAllowWhileIdle` (falling back to `setAndAllowWhileIdle` if permission is restricted).
  - Maintains a durable alarm registry in `SharedPreferences` to ensure alarm persistence across process restarts.
  - Posts heads-up notifications with full-screen intent (`MainActivity`) over the Android lock screen/keyguard (`setShowWhenLocked(true)`, `setTurnScreenOn(true)`).
  - Ringtone playback and vibration management with volume controls.
  - Dynamic permission introspection (`canScheduleExactAlarms`, `hasFullScreenIntentPermission`, `hasNotificationPermission`).
- **Broadcast Receivers:**
  - `LafinaReminderReceiver.kt`: Intercepts `ACTION_TRIGGER_REMINDER` intents to trigger full-screen reminder call activities or post heads-up notifications with **Accept** and **Decline** actions.
  - `ReminderAlarmReceiver.kt` & `ReminderBootReceiver.kt`: Specialized receivers ensuring complete backward-compatible intent routing and reboot handling.
- **Active Call Foreground Service (`LafinaReminderService.kt`):**
  - Runs with `ServiceInfo.FOREGROUND_SERVICE_TYPE_MICROPHONE` and partial wake locks to keep the process active during simulated reminder phone calls.
  - Includes a 10-minute safety timeout to prevent accidental battery drain.

### TypeScript Scheduler & Poller (`src/scheduler/`)
- **`reminderAlarm.ts`:** Bridges JavaScript reminder state with the Android native module (`scheduleReminderAlarm`, `cancelReminderAlarm`, `reconcileReminderAlarms`).
- **`reminderActions.ts`:**
  - `snoozeReminderAction`: Reschedules reminder with incremented `snooze_count` according to user preferences (`snooze_once`, `snooze_multiple`, `strict_no_snooze`).
  - `acknowledgeReminderAction`: Marks reminder status as `acknowledged` and clears alarms/notifications.
  - **Decoupled Task Invariant:** Acknowledging an alert strictly preserves the underlying task's incomplete status (`isCompleted === false`).
  - `autoSnoozeReminderAction`: Handles automated snooze timeout transitions.
- **`reminderPoller.ts`:** Foreground polling daemon checking SQLite for due reminders and dispatching `LAFINA_CALL_TRIGGER` events.
- **`reminderRescheduler.ts`:** Comprehensive lifecycle recovery function:
  - Reschedules all future pending reminders to `AlarmManager`.
  - Immediately triggers near-due reminders scheduled within the last 3 minutes.
  - Automatically marks stale past reminders older than 15 minutes as `missed`.
- **`App.tsx` Integration:** Rescheduling and foreground poller wired to application launch, foreground resume, user login, and cloud sync pull.

## 5. Architectural Hardening & Forbidden Scope Enforcement

- **Strict Elimination of Business Modules:**
  - Zero business dashboards, business roles (`manager`, `employee`, `business`), business tasks, business work blocks, company chat, or team invitation flows.
- **Strict Elimination of Gmail Modules:**
  - Zero Gmail APIs, OAuth scopes, mail sync jobs, or inbox screens.
- **Strict Elimination of Study Tool Bloat:**
  - Excluded all Pomodoro timers, Flashcards decks, Study Notes, and Meeting recording/transcription modules.
- **Zero Heavy Model Binaries:**
  - Eliminated Kokoro 82M ONNX binaries (`kokoro-v0_19.onnx`, `af_bella.bin`, `cmudict.txt`), reducing release bundle size and system resource footprint.
- **Automated Architectural Verification:**
  - `scripts/check-architecture.mjs` executes AST checks over all 126 TypeScript modules in `src/`, verifying 0 circular dependencies and 0 forbidden imports.
