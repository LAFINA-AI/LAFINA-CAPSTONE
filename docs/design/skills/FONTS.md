Lexend weights 400/500/600/700 extracted from the owner-provided HTML embedded WOFF2 fonts and converted losslessly to Android TTF. Used in Skills and shared Notes/To-do UI (including those editors opened from Schedule). App font scaling stays enabled.

https://scripts.sil.org/OFL

The official font license is bundled at `android/app/src/main/assets/fonts/OFL-Lexend.txt`, retrieved from https://raw.githubusercontent.com/google/fonts/main/ofl/lexend/OFL.txt. The four modified format/family names are Lexend400, Lexend500, Lexend600 and Lexend700; the reserved name “RevReading Lexend” is not used. Font size scaling is enabled throughout the new pages.
