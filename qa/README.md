# QA templates — not results

These files are blank audit/evaluation instruments. They contain **no executed tests**. `REQUIREMENTS-MATRIX.md` maps product requirements to phases; `REAL-DEVICE-QA.md` is human phone validation; `COMMAND-DATASET.md` starts the test-corpus design; CSVs store actual results once measured. Codex must never replace placeholders with fabricated figures. Reports belong under `docs/reports/` created by the implementing agent.
